GITHUB PAGES
Lade alle Dateien aus diesem Ordner in dein bestehendes GitHub-Pages-Repository und ersetze die alten Dateien.
Wichtig: index.html, manifest.webmanifest, sw.js sowie die drei Icon-Dateien müssen im selben Ordner liegen.

PDF-IMPORT
Die PDF-Auswertung läuft im Browser auf deinem Gerät. Beim ersten PDF-Import wird PDF.js von cdnjs geladen; dafür ist einmalig eine Internetverbindung nötig. Danach kann der Browser die Bibliothek zwischenspeichern.
